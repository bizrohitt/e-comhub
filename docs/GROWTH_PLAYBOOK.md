# GROWTH PLAYBOOK

Marketing, psychology and monetization. **Ethical persuasion only** — no fake scarcity, no fake
counters, no dark patterns, no claim we can't prove. We're building a trust asset; one fake number
destroys more value than it creates.

---

## 1. The growth model

```
SEO (compounding) ─┐
Community answers ─┼→ tool page → instant value → [copy result / share link / embed]
Directories ───────┘                            ↘ optional email (after value, never before)
                                                   ↘ newsletter → new tool announcement → return visit
```

Three loops, in priority order:

1. **Search loop** (primary): more tools → more keywords → more impressions → more links → better
   rankings for the next tool. Compounds, free, slow.
2. **Share loop**: a result URL that restores state is forwardable. A founder sends "here's the
   margin math" to their partner → a new user who already trusts the sender.
3. **Embed loop**: agencies and bloggers embed a calculator; the required visible backlink feeds
   loop 1. The only link-building that scales without begging.

## 2. Ethical psychology — what we use and where

| Principle | Where it appears | Our honest version |
|---|---|---|
| **Reciprocity** | Whole product | Full value with no signup. The ask comes after, never before |
| **Loss aversion** | Discount & margin tools | "At 20% off you need 61% more orders to make the same profit" — true math, not a scare tactic |
| **Anchoring** | Tool page footer | "Tools like this are usually behind a $29/mo plan" — only where verifiably true |
| **Authority** | Formula + source blocks | Show the equation and cite the source. Experts link to pages that show their work |
| **Social proof** | Tool pages, later | Only real first-party numbers: "used 4,812 times this month" — rendered only when the count is real and above a floor |
| **Commitment** | Multi-step tools | Progress bar + state kept in the URL so nothing is lost |
| **Endowment** | Result actions | "Your scenario" — copy, download, share, keep it |
| **Curiosity gap** | Headlines, newsletter | "The margin number most stores get backwards" — then actually answer it |
| **Default effect** | Every form | Sensible prefilled defaults + a "Load example" button; zero blank-page paralysis |
| **Friction removal** | Everywhere | No login, no modal, no cookie banner, no interstitial |

**Banned outright:** countdown timers that reset, "3 people are viewing", fake stock levels,
pre-ticked consent, "No thanks, I hate profit" confirm-shaming, email-to-unlock-result gates,
exit-intent popups on first visit.

## 3. Email capture that doesn't poison the well

**Placement:** below the result, after the user has already got what they came for. Never a modal,
never a gate, never on page load.

**Offer (must be a genuine upgrade, not the same thing):**
- "Email me this scenario as a spreadsheet"
- "The 1-page pricing cheat sheet (PDF)"
- "New tools when they launch — about one email a month"

**Mechanics:** unchecked consent box, consent text stored verbatim on the row, double opt-in,
one-click unsubscribe with no login, delete-on-request. Target: a **small, warm list** we can email
honestly, not a big dead one.

**Measure:** capture rate per tool. If a tool converts at <0.5%, the offer is wrong for that
audience — change the offer, don't add friction.

## 6. Monetization ladder (nothing before Phase 8)

| Stage | Mechanism | Trigger | Guardrail |
|---|---|---|---|
| 1 | Affiliate links where genuinely relevant | 5k monthly visits | Disclosed, max one per page, never above the tool |
| 2 | Reserved display ad slots | 20k monthly visits | Fixed-height containers so CLS stays <0.05; never between input and result |
| 3 | "Pro" limits | Clear demand | Free tier stays genuinely useful forever: bulk/history/API are the paid lines, not the core tool |
| 4 | Agency white-label embeds | Inbound requests | Flat annual, self-serve |
| 5 | Sponsored tool page | Brand interest | Labelled "Sponsored", content still independent |
| 6 | Done-for-you services | Founder's time | Highest margin, lowest scale |

**Permanent rule:** monetization never degrades the free tool. No ads inside the calculator, no
result delays, no "upgrade to see your number".

---

## 7. Retention

- **Newsletter**: monthly, one actionable tip + the new tools. Plain text, no tracking pixel.
- **Changelog page**: proves the site is alive; indexable.
- **Bookmarkability**: fast, stable URLs, works on mobile, remembers nothing it shouldn't.
- **"Report an issue" link on every tool**: free QA, and it tells users a human maintains this.
- **Tool requests**: a one-field form; requests + `SearchMiss` set the roadmap.

## 8. Positioning (the words that do the work)

> **Free tools for people who sell things online. No signup. No upsell. Your numbers stay in your browser.**

Competitors gate results behind email, load 2 MB of tracking, and show stale fee data. Our three
visible differentiators, repeated everywhere: **instant**, **private**, **shows the formula**.
