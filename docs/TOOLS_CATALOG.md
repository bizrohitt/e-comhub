# TOOLS CATALOG

**129 planned tools · 0 live · 0 in progress.** Status is the single source of truth for what
exists. Update the row in the same session you build the tool.

**Columns** — `S` simple/client-side, `A` advanced (hybrid or server). `Mode`: `client` (browser
math), `server` (Python), `hybrid` (needs an ADR). `Phase`: when it's scheduled.
**Status:** `planned` · `building` · `live` · `parked`.

**Rules:** one tool = one primary keyword = one URL. Variants (`?platform=` style content) get their
own URL only when the page content genuinely differs. A tool is `live` only when it has tests, a
formula/explanation block, 3+ FAQs, related links and passes the page budget.
